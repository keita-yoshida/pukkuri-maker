# ぷっくりメーカー / pukkuri-maker

テキスト・SVG・DXF から、うちわ文字のような「ぷっくり」した 3D プリント用 STL を作るブラウザツールです。
依存パッケージゼロの静的サイトで、処理はすべてブラウザ内で完結します（ファイルはアップロードされません）。

## 使い方

```sh
python3 -m http.server 8000   # もしくは npx serve
# http://localhost:8000 を開く
```

`file://` で直接開くと ES モジュールが CORS で読み込めないため、簡易サーバー経由で開いてください。
GitHub Pages にそのまま置くこともできます。

1. **形をつくる** — テキストを打つか、SVG / DXF を読み込む
2. **ぷっくり具合** — 盛り上がり方（表面張力／クラシック）と高さ・とろみを調整
3. **オプション** — フチ（縁取り）や台座（うちわ土台・キルト模様）を足す
4. **プレビューと書き出し** — STL をダウンロード

## 仕組み

```
入力（テキスト / SVG / DXF）
  └─ raster.js  … canvas に描いて2値マスク化（n×n グリッド）
      └─ edt.js   … 正確なユークリッド距離変換（Felzenszwalb & Huttenlocher）
          ├─ capillary.js … 表面張力の形をPDEで解く（既定）
          └─ puff.js  … レイヤーを合成して高さ場をつくる
              ├─ preview.js … 法線シェーディングでプレビュー描画
              └─ mesh.js    … 高さ場 → 三角形 → binary STL
```

### 表面張力モード（既定）

水やレジンが輪郭にピン留めされて盛り上がった形は、表面張力 γ で割った
Young-Laplace 方程式の解です（`capillary.js`）。

```
∇·( ∇h / √(1+|∇h|²) )  =  h / Lc²  −  P        （マスク内部）
h = 0                                          （輪郭＝接触線）
```

- **Lc = √(γ/ρg)**「とろみ」。液体が重力に負けずに盛り上がれる幅の目安で、
  水なら約 2.7mm、UVレジンなら約 1.8mm。小さいほど広い面が平らにつぶれ、
  大きいほど風船のように膨らみます。
- **P = Δp/γ** 内部圧力＝「どれだけ液を盛ったか」。UIでは訊かず、
  いちばん高い所が指定の高さになるよう二分探索で決めています。

解き方は遅延拡散係数（`1/√(1+|∇h|²)` を1反復前の h から作る）＋
赤黒 Gauss-Seidel を画像ピラミッド上で粗→細に。粗いレベルで圧力を安く決めて
細かいレベルに渡すので、384² で 200〜300ms 程度です。

これにより、距離ベースでは出せなかった以下が自然に出ます。

- 細い線は低く、太い所は高い（液体は幅で高さが決まる）
- 線の交差部が自動的にフィレットされる
- 広い面は毛管長で頭打ちになり、ベタっと平らになる

「細い線の底上げ」は物理どおりだと細部が低くなりすぎるときの補正で、
クラシックの円弧を下限として `max()` 合成します。0 にすると純粋な物理形状です。

### クラシックモード

輪郭からの距離 d を円弧 `h = H·√(1-(1-d/R)²)` に写す方式。速くて均一ですが、
太さに関係なく同じ高さまで上がり、広い面は台地になります。

### メッシュ

セル単位の占有判定（4隅すべてが内側のセルだけを立体とみなす）で作るため、
上面・底面・側面が同じ境界辺を共有し、閉じた（水密な）STL になります。
液面は接触線で厚みゼロになり印刷できないので、「最小の厚み」で下駄を履かせています。

## 各パラメータの目安

| 項目 | 目安 | メモ |
|---|---|---|
| 全体サイズ | 60–120 mm | 出力の一辺（円なら直径） |
| いちばん高い所 | 3–6 mm | 高すぎるとサポートが必要になりがち |
| とろみ (Lc) | 1.5–3 mm | 水 2.7 / レジン 1.8 が実物の目安 |
| はみ出し | 0–0.5 mm | 液がフチから膨らむ量 |
| 細い線の底上げ | 0–0.5 | 0 で物理どおり、細字なら 0.4 前後 |
| 最小の厚み | 0.8–1.2 mm | 接触線が薄すぎて印刷できないのを防ぐ |
| メッシュ解像度 | 標準 (384) | 高くすると STL が数十 MB になります |

初期状態は「文字だけ」です。フチ（縁取り）と台座（円・角丸四角・キルト模様）は
オプションの折りたたみから有効にできます。

## 入力形式について

- **SVG** — `fill` のある閉じたパスが最もきれいに出ます。ラスタ化して扱うので、
  外部フォント参照のある `<text>` は事前にアウトライン化してください。
- **DXF** — LINE / LWPOLYLINE（bulge 対応）/ POLYLINE / CIRCLE / ARC / SPLINE（制御点近似）
  を読みます。閉じた図形は塗りつぶし、開いた線は指定した太さでストロークします。

## テスト

```sh
node test/smoke.mjs
```

距離変換の値、高さ場の妥当性、DXF パース、生成メッシュが「全ての有向辺がちょうど
1 回ずつ現れる」＝閉じていて向きが揃っていること、そして表面張力ソルバが
「太い線は細い線より高く盛り上がる」「Lc が小さいと広い面が平らになる」
「指定した高さに収束する」ことを検証します。
