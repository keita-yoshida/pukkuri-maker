# ぷっくりメーカー / pukkuri-maker

テキスト・SVG・DXF から、うちわ文字のような「ぷっくり」した 3D プリント用 STL を作るブラウザツールです。
依存パッケージゼロの静的サイトで、処理はすべてブラウザ内で完結します（ファイルはアップロードされません）。

## 使い方

```sh
python3 -m http.server 8000   # もしくは npx serve
# http://localhost:8000 を開く
```

`file://` で直接開くと ES モジュールが CORS で読み込めないため、簡易サーバー経由で開いてください。
GitHub Pages にそのまま置くこともできます。

1. **形をつくる** — テキストを打つか、SVG / DXF を読み込む
2. **ぷっくり具合** — 盛り上がり方（表面張力／クラシック）と高さ・とろみを調整
3. **オプション** — フチ（縁取り）や台座（うちわ土台・キルト模様）を足す
4. **プレビューと書き出し** — STL をダウンロード

## 仕組み

```
入力（テキスト / SVG / DXF）
  └─ raster.js  … canvas に描いて被覆率（アンチエイリアスのα）を取る
      └─ sdf.js   … 被覆率からサブピクセル精度の符号付き距離場 φ をつくる
          ├─ edt.js … 正確なユークリッド距離変換（表面張力ソルバ用）
          ├─ capillary.js … 表面張力の形をPDEで解く（既定）
          └─ puff.js  … レイヤーを合成して高さ場をつくる
              └─ mesh.js    … 高さ場 → 三角形（emitTriangles）
                  ├─ buildMesh  … binary STL 書き出し
                  └─ viewer3d.js … WebGL で 3D プレビュー
                      （preview.js は WebGL 不可時の平面フォールバック）
```

### 表面張力モード（既定）

水やレジンが輪郭にピン留めされて盛り上がった形は、表面張力 γ で割った
Young-Laplace 方程式の解です（`capillary.js`）。

```
∇·( ∇h / √(1+|∇h|²) )  =  h / Lc²  −  P        （マスク内部）
h = 0                                          （輪郭＝接触線）
```

- **Lc = √(γ/ρg)**「とろみ」。液体が重力に負けずに盛り上がれる幅の目安で、
  水なら約 2.7mm、UVレジンなら約 1.8mm。小さいほど広い面が平らにつぶれ、
  大きいほど風船のように膨らみます。
- **P = Δp/γ** 内部圧力＝「どれだけ液を盛ったか」。UIでは訊かず、
  いちばん高い所が指定の高さになるよう二分探索で決めています。

解き方は遅延拡散係数（`1/√(1+|∇h|²)` を1反復前の h から作る）＋
赤黒 Gauss-Seidel を画像ピラミッド上で粗→細に。粗いレベルで圧力を安く決めて
細かいレベルに渡すので、384² で 300〜400ms 程度です。

**この演算子では、赤黒反復は偶数格子と奇数格子の差を1掃引あたり 0.998 でしか
減衰させません**（実質そのまま残る）。そのためピラミッドのアップサンプルは
最近傍ではなく双線形で行い（ブロック状の段差＝高周波を入れない）、最後に
`[1 2 1]` の1パスを内部だけに掛けています（このカーネルは市松模様に対して厳密に0）。
これを入れる前は振幅0.034mmの1ピクセル周期の波が全面に残り、
解像度を上げても波が細かくなるだけで消えませんでした。係数は面中心差分で作ります
（格子点で中心差分を取ると偶奇格子が分離するため）。

これにより、距離ベースでは出せなかった以下が自然に出ます。

- 細い線は低く、太い所は高い（液体は幅で高さが決まる）
- 線の交差部が自動的にフィレットされる
- 広い面は毛管長で頭打ちになり、ベタっと平らになる

「細い線の底上げ」は物理どおりだと細部が低くなりすぎるときの補正で、
クラシックの円弧を下限として `max()` 合成します。0 にすると純粋な物理形状です。

### 接触線の扱い

ソルバの計算領域も φ で切ります（Shortley-Weller のカットセル）。2値マスクのままだと
計算領域の縁が1ピクセル単位に量子化され、接触線から等距離の点なのに高さが最大0.5mm
食い違います。この誤差は**輪郭に沿ったリッジ**として出るので、フチなしのときは
シルエットと重なってMSに均され見えませんが、フチを付けると面の途中に露出して
いちばん目立つアラになります。

加えて、最細レベルの掃引を増やして（12→60）深部の収束を詰め、
残った境界層の誤差は **φ の等値線に沿った方向にだけ** 平滑化して均します
（半径方向のプロファイルには触れないので、立ち上がりの形は変わりません。
帯の縁では効果を0に向けてフェードさせます。急に止めるとそこにキンクが出ます）。

真円で測った周方向のばらつき（接触線から2ピクセル内側）:
**0.41mm → 0.09mm**、隣接ピクセル間では **0.033mm → 0.008mm**。

### クラシックモード

輪郭からの距離 d を円弧 `h = H·√(1-(1-d/R)²)` に写す方式。速くて均一ですが、
太さに関係なく同じ高さまで上がり、広い面は台地になります。

### 3Dプレビュー

`viewer3d.js` は STL 書き出しと**同じ `emitTriangles()`** からジオメトリを作るので、
画面に見えているものが書き出される立体そのものです。ライブラリは使わず、
行列・シェーダ・軌道カメラは自前（依存パッケージゼロを維持するため）。

- ドラッグで回転、ホイールで拡大縮小、ダブルクリックで初期位置、「真上から」ボタン
- 上面の法線は三角形からではなく**高さ場の勾配**から作っています。四角形の分割方向が
  交互になる関係でフラット法線だと縞が出るためで、側面はシルエットが甘くならないよう
  フラットのまま
- WebGL が使えない環境では `preview.js` の平面シェーディングに自動で切り替わります

### 輪郭とメッシュ

輪郭はピクセルの塗り／塗らないではなく、**符号付き距離場 φ のゼロ等値線**です。

1. canvas のアンチエイリアスされたα値をそのまま被覆率として受け取る（`raster.js`）
2. 部分被覆のピクセルでは、辺は被覆率の勾配方向に `(被覆率 − 0.5)` だけ離れた所にある。
   その**サブピクセル位置**を種として、Danielsson のベクトル距離変換で全面に伝播（`sdf.js`）
3. `mesh.js` が各セルをマーチングスクエアで φ=0 に沿って切る

輪郭の誤差は**約0.09ピクセル**（90mm・解像度384で 0.02mm）。占有判定だと必ず0.5ピクセル＝
半セルの階段が出るので、そこが解像度を上げても消えなかったジャギーの正体でした。
残差は「被覆率→距離」の線形近似によるもので、軸に平行な辺では厳密、斜め45°で最大0.15ピクセルです。

φ を持ったことで副次的な利点もあります。太らせ・はみ出し・フチはピクセル単位の膨張ではなく
`φ + r` という厳密なオフセットになり、台座は解析的な φ なのでグリッドの影響を一切受けません。

水密性は、隣り合うセルが共有辺上で同じ2つの φ から同じ交点を補間することで担保しています
（上面・底面が辺で一致し、側面は切り口とグリッド外周にだけ立つ）。

液面は接触線で厚みゼロになり印刷できないので、「最小の厚み」で下駄を履かせています。
**どの面も接触線では必ずこの高さになる**ので、境界頂点の z は格子値から補間せず
その定数を使います。補間すると、交点がたまたま肩のどこに落ちたかで rim の高さが
0.80〜1.35mm と暴れ、フチがガタガタに見えていました。

## 各パラメータの目安

| 項目 | 目安 | メモ |
|---|---|---|
| 全体サイズ | 60–120 mm | 出力の一辺（円なら直径） |
| いちばん高い所 | 3–6 mm | 高すぎるとサポートが必要になりがち |
| とろみ (Lc) | 1.5–3 mm | 水 2.7 / レジン 1.8 が実物の目安 |
| はみ出し | 0–0.5 mm | 液がフチから膨らむ量 |
| 細い線の底上げ | 0–0.5 | 0 で物理どおり、細字なら 0.4 前後 |
| 最小の厚み | 0.8–1.2 mm | 接触線が薄すぎて印刷できないのを防ぐ |
| メッシュ解像度 | 標準 (384) | 高くすると STL が数十 MB になります |

初期状態は「文字だけ」です。フチ（縁取り）と台座（円・角丸四角・キルト模様）は
オプションの折りたたみから有効にできます。

## 入力形式について

- **SVG** — `fill` のある閉じたパスが最もきれいに出ます。ラスタ化して扱うので、
  外部フォント参照のある `<text>` は事前にアウトライン化してください。
- **DXF** — LINE / LWPOLYLINE（bulge 対応）/ POLYLINE / CIRCLE / ARC / SPLINE（制御点近似）
  を読みます。閉じた図形は塗りつぶし、開いた線は指定した太さでストロークします。

## テスト

```sh
node test/smoke.mjs
```

距離変換の値、高さ場の妥当性、DXF パース、生成メッシュが「全ての有向辺がちょうど
1 回ずつ現れる」＝閉じていて向きが揃っていること、そして表面張力ソルバが
「太い線は細い線より高く盛り上がる」「Lc が小さいと広い面が平らになる」
「指定した高さに収束する」ことを検証します。
